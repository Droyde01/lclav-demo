# L' Clav · demo

Demo del website de L' Clav (Miami). Sitio estático: `index.html`, `css/`, `js/`, `data/`, `assets/`.
Los ajustes (WhatsApp, Instagram, horario, clips del cuarto, zonas clicables) están en `js/config.js`.
Los formularios en este demo no envían datos; en el hosting final se conectan a un servicio de formularios.
